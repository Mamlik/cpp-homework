# C++: первая и вторая часть

Мои домашние задания по двум частям курса МИФИ «Введение в программирование». Изначально задания и решения хранились на GitLab Manytask под логином `mamik`.

## Структура

| Папка | Курс | Содержание |
| --- | --- | --- |
| [part-1](part-1/) | Первая часть, 2024–2025 | Основы C++, строки, контейнеры, итераторы, алгоритмы, шаблоны, ООП, управление памятью и обработка ошибок |
| [part-2](part-2/) | Вторая часть, 2025 | Многопоточность, атомарные операции, условные переменные, дополнительные задания и поэтапная реализация торрент-клиента |

Во второй части также сохранены задания раздела `python-basics`, входившие в исходный репозиторий курса.

## Сборка и проверка

Условия и файлы для локальной проверки находятся в папках отдельных задач. Требования к окружению и порядок запуска описаны в исходных инструкциях:

- [Первая часть — инструкция курса](part-1/README.md).
- [Вторая часть — инструкция курса](part-2/README.md).

Для задач с Makefile сборка выполняется из папки соответствующей задачи командой `make`.
